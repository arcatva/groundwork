# Frame

Turn a request into a brief the user agrees to, before any code is planned.

## 1 · Gather

- The request in the user's own words, and every ticket, design and decision it links or names.
- Today's behaviour: the code that carries out what the request touches, read to its call chain,
  with `path:line`.

## 2 · Write the brief

In the Brief shape of `contracts.md`: who has the problem and what they cannot do today; the
behaviour as cases on concrete values, listed as "Enumeration" in `SKILL.md` says, the cases the
request leaves out among them; and what is out of scope. Ask each open case in the Question shape,
all together, most consequential first.



**Gate.** Every case names its source, every open question is answered, and the user agrees to the
brief.
